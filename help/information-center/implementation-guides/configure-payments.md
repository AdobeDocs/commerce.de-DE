# Konfigurieren von Zahlungen

[!DNL Payment Services] bietet Käufern mehrere Zahlungsmethoden, einschließlich zinsfreier Raten, und bietet Händlern ein einheitliches Dashboard für die Verwaltung von Zahlungen, Bestellungen und Rechnungen.

>[!NOTE]
>
>Dieses Handbuch gilt, wenn Adobe Commerce (Cloud oder On-Premise), Adobe Commerce as a Cloud Service oder Magento Open Source Transaktionen verarbeitet. Folgen Sie bei Adobe Commerce Optimizer-Projekten diesem Fluss nur, wenn das Transaktions-Backend eine dieser unterstützten Plattformen ist. Wenn Transaktionen von einem Drittanbieter-Backend verarbeitet werden, verwenden Sie stattdessen die Zahlungseinstellungen dieses Backends.

## Erste Schritte

1. Überprüfen Sie die Verfügbarkeit der Produktversion und des Landes in [Kompatibilität mit Zahlungsdiensten](https://experienceleague.adobe.com/en/docs/commerce/payment-services/compatibility).

1. Folgen Sie dem [Fluss Onboarding-Zahlungsdienste](/help/payment-services/onboard.md).

1. Wenn Ihre Commerce on Cloud- oder On-Premise-Instanz nicht mit Commerce Services verbunden ist, befolgen Sie zunächst [Einrichten von Commerce Services](set-up-commerce-services.md).
